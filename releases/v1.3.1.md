# screensaver4wayland v1.3.1

静景：面向 GNOME Wayland 的图片屏保。

## 功能

- 闲置后自动进入屏保，鼠标或键盘操作后退出。
- 每块显示器可独立设置图片、轮播文件夹、缩放和轮播间隔。
- 支持 JPEG、PNG、BMP、WebP；动态 WebP 显示第一帧。
- 原生图形控制台，可立即应用与双屏预览。
- 显示器 SVG 图标，支持 GNOME 应用菜单与任务切换器。
- MIT 开源许可证。

## 下载与安装

普通用户下载 `screensaver4wayland_1.3.1-1_all.deb`，在下载目录执行：

```bash
sudo apt install ./screensaver4wayland_1.3.1-1_all.deb
screensaver4wayland --settings
```

`apt` 会安装所需的 Python/GTK/WebP 依赖。应用列表中也可以搜索“静景”。下一次登录 GNOME Wayland 时自动启动，界面右上角可暂停自动屏保。

源码请下载 `screensaver4wayland-1.3.1-source.tar.gz` 或 `.zip`。校验下载：

```bash
sha256sum --ignore-missing -c SHA256SUMS
```

## 兼容范围

实际验证环境为 **Ubuntu 22.04、GNOME 42、Wayland、amd64**。安装包不含 CPU 架构相关代码，标记为 `all`；其他 GNOME 版本及其他硬件架构尚未实测。KDE、Sway 等桌面目前未适配。

本程序显示图片，不替代 GNOME 密码锁屏；原有锁屏、息屏与休眠设置继续生效。

## 从手动安装版本迁移

如果之前运行过源码里的 `install.py`，请先在源码目录执行以下命令，再安装 `.deb`，避免用户目录中的旧程序覆盖系统版本。个人配置会保留。

```bash
python3 install.py --uninstall
sudo apt install ./screensaver4wayland_1.3.1-1_all.deb
```
